# Brasa Lenta

Landing page da hamburgueria artesanal Brasa Lenta, com cardápio de destaque (6 burgers e 4 acompanhamentos) e pedido pelo WhatsApp.

## Como funciona

- Toque em **+** nos itens para montar o pedido.
- A sacola no rodapé mostra os itens e o total em reais (R$).
- O botão **Enviar no WhatsApp** abre a conversa com a mensagem pronta (itens, total, nome e forma de entrega).

## Como abrir

É um único arquivo `index.html`, sem dependências. Abra direto no navegador ou acesse pelo GitHub Pages.

O endereço da loja na página é de exemplo.
